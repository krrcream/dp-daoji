一句话

这是用 LR2IR 的 records 推定的発狂 DP 难度表，分 EASY / HARD 两套。它不是官方表，也不是某个人的主观排行；适合看“大概在哪个难度段”，不适合拿相邻阶做绝对比较。

V0.3 的档位基本由统计计算得出，没有逐谱人工调级；大境先按社区评级对齐，缺少评级时回落到源表等级。因此仍可能有个别谱定级偏歪。

一、收录范围

1. 表里到底有什么？

  • 两套表：EASY（♂◇ 固元道途，EASY CLEAR 通过线）和 HARD（♂◆ 鋒殺剣途，HARD CLEAR 通过线）。
  • 每套 2,070 张谱，7 大境 × 7 小阶 = 49 阶；每境末尾另有 1 个待考阶，不计入 49 阶。
  • 两套表使用同一批 2,070 张谱；因为通过线不同，同一张谱在两套表里的档位可能不一样。
  • 大境从低到高：錬気、築基、結丹、元嬰、化神、錬虚、大乗。
  • 每境末尾的「疑」（EASY，代号 EBn-?）/「晦」（HARD，代号 HBn-?）是待考阶，不是“比 1–7 阶更难”的意思。

2. 收录了哪些来源表和等级？

V0.3 的模型覆盖以下来源：

来源表等级
「δ難易度表」δ11
「DPBMSと諸感」☆11弱、☆11中、☆11強、☆12

本表的定位是收录 IIDX DP 八段左右到接近 IIDX DP 皆传的难度段。超过这个范围的谱，游玩样本更少，难度难以稳定估计，所以暂时只收这些；以后有机会再做升仙表。

2,070 张的构成：

  • 1,792 张由五级 GRM 直接估计；
  • 178 张 DP Satellite 谱未通过新 GRM 的入模筛选（样本不足，或通过率、拟合异常），用上一版 1PL 的难度值做线性映射补位；
  • 100 张只有 mocha 星级/评分数据、没有进入 LR2IR 目标谱集合的谱，用外部回归预测补位。

不是这些源表的所有谱都收。样本太少、通过率极端、拟合过差的谱会被剔除，不会硬塞进表里。

二、收录的数据

3. 成绩数据从哪来？

  • LR2IR 全量公开存档 v3，快照时间 2026-05-29。
  • LR2IR 已于 2026-05-31 关站；之后产生的新成绩不会进入这份数据。
  • 压缩包约 3.27 GiB，解压后的数据库约 8.6 GB。
  • 来源仓库：zkldi/lr2ir-dataset（Unlicense）。

4. 数据怎么清洗？

  • 只保留 14 keys（DP） 谱面；剔除 is_cheated 和 suspended。
  • 每个「玩家 × 谱面」只取一条最好成绩，避免同一人多次游玩被当成多个独立观测。
  • 只用非随机谱面：排除 乱 / SR，保留 正 / 鏡 / 換。
  • 段位（dan）不进入模型，只用于外部效度校验。

5. 难度是怎么估的？

用 五级评分反应模型（GRM：FAILED / EASY / NORMAL / HARD / FC） 在 LR2IR 公开存档上拟合；EASY 表取 FAILED→EASY 的门槛，HARD 表取 NORMAL→HARD 的门槛。大境按社区评级对齐，缺少评级时回落到源表等级；小境按模型估出的难度排序。

6. 会公开玩家数据吗？

不会。公开字段只有 md5、sha256（有则）、标题、档位和 comment；不包含玩家昵称、逐人成绩、b / θ / 样本量。

三、误差与使用建议

7. 为什么会有误差？

  • DP BMS 玩家池小。 很多谱的游玩样本本来就少，难度估计的方差会比较大。
  • 样本少或玩家池特殊时，档位容易在相邻阶之间摆动，甚至出现明显偏离。
  • 有些谱只有随机谱面成绩，或成绩被剔除，实际可用观测更少。
  • 用外部数据补位的谱没有进入 LR2IR 建模，可靠性更低；这类预测对冷门谱可能偏差较大。
  • 模型不可能拟合所有谱；拟合不理想的谱也可能只是数据噪音，而不是真的“個人差”。

8. 那还能用吗？

可以，但要按“大概参考”来用：

  • 同境、相邻阶的谱通常确实接近，跨大境看整体趋势也可靠。
  • 相邻阶别当绝对结论。 1–2 阶的先后很容易受样本和玩家池影响，不要拿它做实力认证、门票或攻击他人的依据。
  • 看到「疑 / 晦」，把它理解成“现有数据不足以稳定归入 1–7 小阶”，不是“最难”。

9. 「疑 / 晦」是什么？

「疑 / 晦」是每境末尾的待考阶，表示现有数据不足以稳定归入 1–7 小阶，不代表它们最难。样本少、只有随机成绩、外部补位、玩家池异常等情况都可能造成这种不确定。

它也可以当作一个不确定性提示，但它不是完整的低样本标记：有些低样本谱仍在 1–7 阶里，也有些待考阶并不是因为样本少。所以即使某张谱落在 1–7 阶，也不代表它的档位一定稳。这是本表最大的使用限制。

10. 表会更新吗？

  • 数据快照固定在 2026-05-29；LR2IR 已关站，同一数据源不会有新成绩。
  • 如果换数据源、改模型或调整口径，会以新版本号发布。

11. 表名里的 EB / HB 是什么意思？

  • EB = EASY 表，HB = HARD 表。
  • 第一位数字是大境（1–7），第二位是小阶（1–7）；? 表示待考阶（EASY 的「疑」/ HARD 的「晦」）。
  • 例：EB4-? = EASY 表第四境（元嬰）的待考阶；HB2-3 = HARD 表第二境（築基）第三阶。
