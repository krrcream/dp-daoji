常见问题

欢迎来到 DP 修仙界。别人修仙打坐运气，我们修仙左手右手一起双修，14 键齐按。境界越高，谱越难。

壹 模型算分

难度是怎么算的

用模型把每一张得到的谱面直接计算出来。目前难度模型还在初建阶段，相邻境界之间仍有所交叉，不同境界之间不适合做绝对比较，适合看「大概在哪个难度段」。如果觉得哪些谱子不合理，欢迎告诉我具体是哪几首，能加快模型的迭代。

横轴是模型算出的分数，纵轴是真实难度；彩色横条是大境区间，下面四行刻度是各来源表等级（sl / st / ★ / ★★）落在哪里。上 EASY，下 HARD。

贰 来源与张数

收录范围

四套表来自同一批谱：每个尺度下，一张谱只会落进下位或上位其中一张表。合计 10,330 张 —— 下位 EASY 7,781 / HARD 7,574，上位 EASY 2,549 / HARD 2,756。

从下面的第二张表大致能看出，整体已经初具雏形。但闇鍋表的谱训练素材少，有些排列也比较特殊，个别谱会落在看起来很奇怪的位置 —— 这部分只能等模型以后慢慢迭代。闇鍋表本身的难度信息非常少，目前只能做到这样。

左上 = EASY 右下 = HARD 空格 = 0

一、大境 × 来源表

二、来源等级 × 大境

横看是这张表这个等级最后落在哪个大境，纵看是每个大境收了多少张。E1–E7 是下位、E8–E13 是上位。

同一张谱可能同时属于多张来源表，所以横向把来源相加会大于实际张数；实际总量以四套表的合计为准。四套表合计 10,330 张。

叁 十四重天

境界体系

从山脚的凡人到云上的道祖。渡劫期是设定中的过渡境界，当前表没有单独档位。

  1. 01錬気期 Qi RefiningEB1 / HB1

    感应天地灵气，引气入体，淬炼凡躯。刚踏入门槛，一切尚在萌芽。

  2. 02築基期 FoundationEB2 / HB2

    筑就道基，巩固仙根，从此脱离凡俗，是「修仙者」与「凡人」的分界。

  3. 03結丹期 Golden CoreEB3 / HB3

    灵力凝聚成丹，修行路上第一次质变；金丹一成，战力暴涨。

  4. 04元嬰期 Nascent SoulEB4 / HB4

    金丹碎裂，元婴出窍离体，肉身被毁亦可夺舍重生，寿元千载。

  5. 05化神期 Spirit FormEB5 / HB5

    元婴化形，神识外放，初步触摸天地法则，已是凡界顶尖强者。

  6. 06錬虚期 Void RefiningEB6 / HB6

    炼神合道，与天地相融，凡俗巅峰，距飞升只差一步。

  7. 07大乗期 MahayanaEB7 / HB7

    凡俗修为的极致，半只脚踏入仙界，只待天劫降临。

  8. 08渡劫期 Tribulation Crossing—

    九天雷劫的终极考验。渡过飞升，渡不过身死道消。当前表未单独设阶。

  9. 09真仙 True ImmortalEB8 / HB8

    飞升仙界的第一境，脱去凡胎，列入仙班，不入轮回。

  10. 10金仙 Golden ImmortalEB9 / HB9

    修成不朽金身，法力深厚，是仙界的中流砥柱。

  11. 11太乙 TaiyiEB10 / HB10

    领悟太乙大道，接近法则本源，开始触摸「道」的本质。

  12. 12大羅 DaluoEB11 / HB11

    万劫不侵，自在逍遥，跳出时间长河，是仙界最顶层战力。

  13. 13道祖 Dao AncestorEB12 / HB12

    道之始祖，法则化身，一念可定万物生灭。

  14. 14域外 YuwaiEB13 / HB13

    超脱三界外，不在五行中，已无法用常理衡量。
