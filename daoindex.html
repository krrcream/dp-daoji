Import into beatoraja

Add the two header URLs below as difficulty tables

Open the difficulty table manager in beatoraja and add a URL pointing to header.json. Its data_url already points to the matching data.json.

EASY https://raw.githubusercontent.com/krrcream/dp-daoji/main/DP_dao_easy/header.json
HARD https://raw.githubusercontent.com/krrcream/dp-daoji/main/DP_dao_hard/header.json

The repository must be public; raw URLs on a private repository return 404. After updating a table, delete the old entry in beatoraja and add it again so the cached failed URL is not reused.

Method

Data

Full LR2IR archive, 2026-05-29 snapshot. Only non-random charts are used: 乱 (random) and SR excluded; 正 (normal), 鏡 (mirror), and 換 (flip) retained.

Model

Five-level GRM (FAILED / EASY / NORMAL / HARD / FC) estimated with MCMC. Discrimination separates stamina charts from pattern-specific charts.

Tiers

High-sample charts define 7 realms × 7 tiers; charts with sparse data or an unusual player pool are placed in the final pending tier of their realm.
