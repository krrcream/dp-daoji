Welcome to the world of DP immortal cultivation. Other people cultivate by sitting in meditation and channeling qi — we cultivate with both hands at once, literally dual cultivation, smashing 14 keys at the same time. The higher the realm, the harder the chart.

Realm guide

This table is generated statistically, with no per-chart manual adjustment. Because the DPBMS player base is relatively small, insufficient sample data can occasionally lead to questionable placements. If you spot anything that seems wildly off, please let me know — I'd really appreciate your feedback!

It is not an official table, nor a personal ranking; use it to see the approximate difficulty band, not to settle comparisons between adjacent tiers.

How sub-tiers work

  • Each major realm is divided into 7 sub-tiers (1–7). A higher number is harder.
  • Heads up: the 6th and 7th sub-tiers of any realm are the "extreme difficulty" tier. Their difficulty may overlap with sub-tiers 1–2 of the next realm up — so EB2-7 can occasionally be harder than EB3-1, and that's normal. (Think of it like how some ★2 charts are harder than ★3 ones — this is statistically ranked, and DP is such a personal-skill thing, so it's bound to happen.)
  • Every realm also has a final "?" (Pending) slot. These are charts where the statistical model isn't confident where to place them — they're temporarily parked here. This does NOT mean they're harder than sub-tier 7 — it just means "still cultivating, under observation." In the lower table this slot is shown as "Pending" (EASY) / "Obscure" (HARD); in the upper table it is shown as "Que" (闕).

Current coverage: the lower table covers Qi Refining through Mahayana (EB1–EB7 / HB1–HB7). This upper table starts at True Immortal and covers EB8–EB13 (True Immortal through Yuwai). Tribulation Crossing is a story transition with no separate tier in the current tables.

1. What is this

This is an Insane DP upper difficulty table estimated from LR2IR records, positioned above the Daoji table (Guyuan Daotu). It uses the EASY CLEAR pass line only.

It is not an official table, nor a per-chart manual ranking. It is useful for “roughly which band”, not for absolute comparison between neighbouring tiers; Yuwai especially is indicative only.

3. Relation to the Daoji table

  • The 2,070 charts already in the Daoji table (Guyuan Daotu / Fengsha Jiantu) are excluded; nothing is duplicated.
  • The Daoji table uses codes EB1–EB7; this table continues from EB8, so the 5 realms are numbered 8–12 and Yuwai is EB13.
  • The Daoji table has both EASY and HARD; this table is EASY only.

4. Data sources

  • LR2IR public archive v3 (2026-05-29 snapshot) records; LR2IR closed on 2026-05-31.
  • Source difficulty tables: Insane DP table, Insane 14key BMS Yaminabe table, DP Satellite.
  • A small number of charts use community manual ratings as a supplement; these are not separately credited.

5. Method

Difficulty is estimated with a 1PL (Rasch) model fitted on the public LR2IR archive (EASY CLEAR outcome, θ ~ N(0,1)); a core set fixes the scale and realm boundaries, and additions are inserted with θ fixed. Realms follow the community rating where available and source-table levels otherwise; tiers within a realm are ordered by the estimated difficulty.

7. Snapshot and disclaimer

  • Data snapshot: 2026-05-29; LR2IR closed on 2026-05-31, so later scores are not included.
  • No per-player scores or player names are published; only aggregated difficulty values.
  • With few samples, tiers can wobble between neighbouring levels; 3–29 player charts, low-sample charts, and Yuwai are indicative only.
  • This is not an official table. Results are indicative only.

8. Why are there errors?

  • The DP BMS player pool is small. Many charts have few plays, so the variance of difficulty estimates is larger.
  • With few samples or an unusual player pool, tiers can wobble between neighbouring levels or deviate noticeably.
  • Some charts only have random-mod scores, or their scores were removed, so fewer observations are usable.
  • Source-table levels are subjective; level numbers are not directly comparable across tables, and the model uses them only as a within-table reference.
  • Low-sample charts and fixed-θ insertions did not enter the core scale estimation; their reliability is lower, and predictions for obscure charts can be more biased.
  • The model cannot fit every chart; a poorly fitting chart may simply be data noise rather than a real “individual difference”.
  • The upper table has fewer players than the lower table, especially for 3–29 player charts and Yuwai; deviations can be larger, and these tiers are indicative only.
